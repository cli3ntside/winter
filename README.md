# Winter

A Fabric utility mod for Hypixel Zombies on Minecraft 1.21.11.

## Features

### Combat

- Aim Assist with prediction
- Triggerbot
- Quick Swap Macro
- Skill Macro
- Right Clicker

### Automation

- Auto Revive

### Visuals

- Freecam
- Mob, Lucky Chest, and Player ESP
- Mob, Player, and Power-up Nametags
- Bullet Tracers
- Broken Window ESP
- Player Invisibility

### Interface & Tracking

- Power-up Tracker
- Boss Warning
- Scoreboard and Boss Bar Toggle
- Chat Filter
